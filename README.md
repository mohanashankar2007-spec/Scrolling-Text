# HTML Marquee Demonstration

A simple HTML project that demonstrates different scrolling effects using the HTML `<marquee>` tag. This project was created for **Web Technology Lab** to understand the basic attributes and behavior of the marquee element.

## 📖 About the Project

This project demonstrates various marquee effects using only HTML. It includes horizontal scrolling, alternate scrolling, vertical scrolling, and scrolling image with text. The project is intended for educational and laboratory purposes.

---

## ✨ Features

* Left scrolling text
* Alternate (bouncing) scrolling text
* Vertical scrolling text

## 📋 Marquee Attributes Used

| Attribute      | Purpose                                                      |
| -------------- | ------------------------------------------------------------ |
| `behavior`     | Defines scrolling style (`scroll`, `alternate`, `slide`)     |
| `direction`    | Sets the scrolling direction (`left`, `right`, `up`, `down`) |
| `scrollamount` | Controls scrolling speed                                     |
| `bgcolor`      | Sets the background color                                    |
| `height`       | Specifies the height of the marquee                          |
| `width`        | Specifies the width of the marquee                           |
